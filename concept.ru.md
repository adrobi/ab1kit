# ab1kit — Sanger Chromatogram Analyzer (концепт проекта)

> Черновик идеи. Инструмент в духе phymlGUI / rflppicker: открытый, десктопный,
> с RU/EN интерфейсом, ориентированный на рутинные задачи молбио-лаборатории.

## Зачем это нужно (пробел в нише)

Просмотр и разбор хроматограмм Sanger-секвенирования (`.ab1`) — ежедневная
потребность любой лаборатории, но удобного открытого инструмента сейчас нет:

- **FinchTV** — закрыт и больше не распространяется (Geospiza/PerkinElmer).
- **Chromas / Chromas Pro** — условно-бесплатный, платный.
- **SnapGene Viewer** — бесплатный, но только просмотр, без анализа.
- **ABIview (EMBOSS)** — открытый, но древний, без нормального GUI.
- **TraceTrack (2022)** — открытый, но заточен под пакетное сопоставление
  с референсом, не общий просмотр/анализ.

## Минимальная версия (MVP)

1. **Парсинг ABIF** (`.ab1`; опционально `.scf`) — трассы A/C/G/T, phred-качество,
   позиции пиков, call последовательности. База: `Bio.Sequencing.Abi` из BioPython.
2. **Просмотр хроматограммы**: плавный зум/скролл, трассы цветом как в FinchTV,
   шкала качества, линейка позиций, поиск подпоследовательности.
3. **Редактирование чтения**: ручная правка call, reverse-complement,
   обрезка по качеству (скользящее окно, как в Chromas) с подсветкой отрезаемого.
4. **Экспорт**: FASTA / FASTQ (с качеством), копирование последовательности,
   сохранение обрезанного чтения.
5. **Батч-режим**: открыть папку файлов, список с качеством по каждому,
   пакетная обрезка и экспорт.

## Версия 1.1+ (то, ради чего стоит делать)

1. **Выравнивание на референс** (встроенный aligner, mafft как опция):
   чтение поверх референса, таблица различий.
2. **Вызов SNP**, включая **гетерозиготные пики** (двойные пики ~50/50),
   с оценкой качества и IUPAC-кодами.
3. **Проверка ожидаемых SNP** — киллер-фича: загружаешь `.ab1` + список ожидаемых
   замен (VCF/таблица, как вход rflppicker) → программа подсвечивает подтверждённые
   генотипы и расхождения. Замыкает цикл: подобрали RFLP/AS-PCR ассай →
   отсеквенировали → подтвердили.
4. Отчёт в Excel/CSV (стиль rflppicker: файл → различия → вердикт).

## Стек и архитектура

- **Python 3.11+**, GUI — **PySide6/Qt** (как в rflppicker).
- Ядро отдельно от UI: `chrom_core/` (парсер, обрезка, выравнивание, вызов SNP)
  + `chrom_cli.py` для командной строки + GUI сверху. Ядро покрыто pytest.
- Тяжёлых зависимостей минимум: BioPython для ABIF; выравнивание — своя простая
  реализация (Smith-Waterman) или subprocess-обёртка над mafft.
- Настройки в JSON-конфиге, i18n через словари (`i18n.py` + translations_en.py).
- Лицензия MIT, бинарник phy-зависимостей не требуется (всё на pip).

## Структура репозитория (заготовка)

```
ab1kit/
├── chrom_core/          # парсер ABIF, trim, align, SNP calling
├── ui/                  # Qt-виджеты: хроматограмма, панель файлов, отчёт
├── chrom_cli.py        # точка входа CLI — команда `ab1kit`
├── tests/
├── examples/            # пара тестовых .ab1 (сгенерировать/взять открытые)
├── README.md / README.ru.md
└── requirements.txt
```

## Критерии успеха MVP

Открыл `.ab1` → увидел читаемую хроматограмму → обрезал → экспортировал FASTA —
за минуту, без интернета и без платных программ.
